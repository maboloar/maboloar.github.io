Why

입력 장치 없이도, 누구나 컴퓨터를 조작할 수 있게

지금은 마우스·트랙패드 같은 전용 입력 장치가 있어야 컴퓨터를 조작할 수 있습니다.

사람

마우스를 쓰기 어려운 사람

신체적 제약이 있으면 표준 입력 장치가 벽이 됩니다.

장소

입력 장치를 둘 수 없는 곳

전시장, 키오스크, 인터랙티브 미디어는 장비 설치와 관리가 부담입니다.

비용

비싸고 맞추기 어려운 전용 장비

특수 마우스와 트래킹 컨트롤러는 비싸고, 사람마다 맞춰 주기 어렵습니다.

기존 방식

카메라 입력도 쉽게 끊깁니다

대부분 손 제스처만 다루거나, 마커를 붙여야 하거나, 가려지는 순간 추적을 잃습니다.

우리의 목표

새 장비를 사지 않고, 이미 있는 카메라와 주변 물건만으로 가려져도 끊기지 않는 믿을 수 있는 입력 장치를 만듭니다.

How to use

물체로, 맨손으로, 펜으로

물체 마우스 OBJECT

  • 영상에서 물체를 드래그해 등록
  • 좌우 이동 → 커서 좌우
  • 카메라에 가까이·멀리 → 커서 위아래

맨손 입력 HAND

  • 손바닥 = 커서 이동
  • 엄지+검지 = 왼쪽 클릭·드래그
  • 엄지+중지 = 오른쪽, 두 손가락 = 스크롤

펜 입력 PEN

  • 펜촉 → 반대쪽 끝, 두 점을 찍어 등록
  • 책상에 닿는 순간을 자동 판정
  • 닿은 동안 책상 좌표로 그리기
옆 카메라 방식좌우는 커서 좌우, 손·물체 크기 변화로 추정한 거리는 커서 위아래로 바꿉니다.

Get started

누구나 따라 하는 첫 설정

  1. iPhone을 카메라로 연결

    Apple 연속성 카메라 (iPhone XR 이후 · iOS 16+). 책상 옆 거치대에 수평 고정, USB 권장

  2. 설치 파일을 받아 더블클릭

    GitHub Releases의 AnyControl-v1.0.0-macOS.command. 빠진 Python·라이브러리는 자동 설치 (막히면 다음 장)

  3. 권한 모두 허용

    카메라, 손쉬운 사용(실제 입력). 허용하지 않으면 동작하지 않습니다

  4. 자동 보정

    안내대로 가만히 → 좌우 → 가까이·멀리 → 집기 → 확인 클릭

  5. 물체 등록

    영상에서 드래그 (펜은 두 점). 어긋나면 [다시 선택]

  6. 가상 모드로 연습 후 실제 입력

    켜면 3초 뒤 시작, ESC로 즉시 정지. 브라우저 탭을 닫으면 약 5초 뒤 자동 종료

잘 추적되는 팁

  • 주변과 색이 뚜렷이 다른 물체·펜
  • 모양이 변하지 않는 물체
  • 밝은 조명
  • 저반사 바닥 (유리 바닥은 아직 약함)
  • 똑같이 생긴 물체 여러 개는 피하기
  • 카메라는 흔들리지 않게 고정

내려받아 더블클릭, 설치는 알아서

Python도 라이브러리도 미리 설치할 필요가 없습니다. 첫 설치에만 인터넷이 필요하고, 이후에는 오프라인으로 동작합니다.

Requirements

2

“적절한 접근 권한이 없기 때문에…”

터미널에 chmod u+x + 공백 한 칸을 입력하고, .command 파일을 터미널로 끌어놓은 뒤 Enter. 그다음 파일을 다시 더블클릭합니다.

실행 파일과 삭제 파일은 각각 따로 처리해야 할 수 있습니다.

Q. macOS에서만 되나요?

현재는 네. 추후 Windows·Linux를 지원하고, GPU 환경에서는 CUDA로 성능을 높일 계획입니다.

Q. 영상이 밖으로 나가나요?
